# Link Expand 浏览器联动扩展

## v0.3.4 自动联动

软件和扩展都更新至 v0.3.4。扩展是选用功能；没有连接扩展，软件也可用公开链接解析或可见 Playwright 窗口回退。Windows 可以用已登录的 Edge；Mac 使用 Chrome，不需要安装 Edge。

1. 加载本文件夹中的扩展（安装方式见下方）；旧版扩展须在管理页重新加载。
2. 启动新版软件，在「下载设置、请求头与浏览器捕获」复制配对码。
3. 在扩展填写软件的本地地址和配对码，点击「启用自动联动」，授予网站读取权限。默认勾选的「没有可用图片时自动截图」还会请求可选调试权限，仅用于软件自己创建的标签页；此项可关闭。
4. 软件显示「Edge / Chrome 已连接」后，只需在软件输入链接，自动返回标题、摘要、图片和媒体资源。下载与复制仍由软件按钮发起。

配对码跨软件重启保留。端口改变时，修改扩展地址后再次启用。浏览器需保持运行。扩展先只读复用已正常打开的同一页面；找不到时使用当前浏览器的登录会话创建静音后台标签页，完成、取消或超时后关闭自己的标签页，不重启浏览器、不切换前台页面、不解密或复制整个用户配置。

没有可用封面时尝试视频画面；授予截图权限时也可截取同一浏览器中的网页。截图时浏览器可能显示标准调试提示，完成即解除。网页仍要求登录或安全验证时，应在浏览器完成后重试。自动读取不能保证通过所有网站的风控。

Cookie / Authorization 只发往本机，不上传解析服务、不写入下载任务文件。新版增加可选 cookies 权限，只为读取所提交网站适用的 Cookie，并将其交给本机 Playwright 回退；保留 HttpOnly、Secure、SameSite 等属性。独立回退浏览器可能在其专用目录保存网站登录数据。配对信息保存在本机。真实 MV3 扩展测试涵盖登录会话、图文、音视频配对、无图截图、取消和标签页清理；用户个人的 B 站登录环境尚待实际使用验收。

## 手动捕获（保留）

用于 Chrome / Edge。手动捕获只处理你启用的当前标签页，十分钟后停止。

1. 解压扩展 ZIP。打开 `chrome://extensions` 或 `edge://extensions`，开启「开发者模式」，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的文件夹。
2. 启动 Link Expand。在「通用下载 → 下载设置、请求头与浏览器捕获」点击「复制扩展配对码」。
3. 点击浏览器工具栏中的扩展，填入软件页面的本地地址与配对码。
4. 在目标网页点击「捕获当前标签页」，授予网站读取权限，然后播放视频。扩展需要读取媒体 CDN 的请求，因此会请求 HTTP/HTTPS 网站权限；实际只处理启用标签页的请求。
5. 点击「刷新列表」，选择播放清单或完整视频请求，点击「导入选中资源」。
6. 回到 Link Expand 点击「读取浏览器捕获」，选择资源、下载。恰好选中一个视频和一个音频时，会额外提供合并选项。

优先选择 M3U8 / MPD 或完整 MP4 / WebM；单独的 TS / M4S 分段无法代表整个视频。`blob:` 是浏览器内部引用，下载器需要实际网络资源。受保护媒体与没有结束时间的直播不作为完整文件下载。

软件重启后配对码仍有效。Cookie / Authorization 只随你主动导入的资源发送至本机，不写入下载任务文件；需要登录的任务重启后应再次捕获、导入。点击「停止」清空本次捕获列表。HLS / DASH 和分离音视频的合并需要免费的 FFmpeg。

## 已登录网页的预览

软件 v0.3.2 起，支持“导入当前网页预览”。在已登录的 Edge / Chrome 正常打开 B 站等网页，打开扩展填写软件地址和配对码，点击该按钮。扩展从你已打开的当前页读取标题、摘要和封面，再打开软件页面显示卡片，避免重新请求被风控拦截的网页。仅导入所选网页信息，不会把登录状态自动共享给所有后台请求。

如需手动下载，在“捕获当前标签页”后播放视频（必要时刷新该网页），选中一个视频和一个音频后点击“导入选中资源与预览”。软件会打开预览和合并下载选项。旧扩展用户须在扩展管理页重新加载新版，软件也需更新至 v0.3.4。启用自动联动后不需逐链接操作这些按钮。
